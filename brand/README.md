# Shunmugasundaram logo files

All files are outlined vector shapes. No font is needed.

## Wordmark
- wordmark-dark.svg: ink #111214, for light backgrounds
- wordmark-white.svg: white, for dark backgrounds
- wordmark-dark-2400.png / wordmark-white-2400.png: for places that don't accept SVG

## Lockup (icon + wordmark)
- lockup-dark.svg: for light backgrounds
- lockup-white.svg: for dark backgrounds

## Icon
- icon-s-dark.svg / icon-s-white.svg: the S on its own, transparent background
- monogram-dark.svg: white S on an ink tile (app icon, profile picture)
- monogram-light.svg: ink S on a light grey tile

## Favicon
- favicon.svg, plus favicon-32.png, favicon-180.png (iPhone home screen) and favicon-512.png

## Rules
- Smallest wordmark size: 10px tall on screen. Below that, use the icon.
- Clear space: the height of the letters on every side.
- Ink #111214 on light, white on dark. Don't recolour, stretch or re-space it.
