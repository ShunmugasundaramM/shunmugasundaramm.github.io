Final, drawn end to end. Setting up: mobile, OTP, set a PIN, then the biometric prompt — the PIN is set first, so declining still leaves a way in. Signing in: mobile, OTP, then Face ID with Use PIN instead, landing on Home. Client ID stays as a secondary link on the first screen, and two recovery paths hang off it, kept separate because they end differently: a blocked account is a request that takes up to a working day, while a password reset is instant once the OTP clears. Activation keeps the three fields from your old app. Resetting the PIN is not a recovery job — it sits in Account › Security behind an OTP, with no PAN asked for. Worth deciding: if the OTP is sent on every sign-in, the biometric step is convenience rather than security — most brokers send it only on a new device or after the session lapses.

Keeps your existing model, so no migration and no support load: the ID people already have still works, and the blocked-account and reset paths stay where they are. Cost: a password to remember, and the slowest first-run of the three.

5Buy and sell

One section, because it is one pad. Buy sits above, sell below, in the same order: pad, conditions, depth, placed, waiting, then the outcomes. Two frames appear on one side only — the CDSL authorisation, which sell needs and buy does not, and the partly-filled state, drawn once on the buy row because it reads the same either way. The two acknowledgements differ only in the number that matters: buy names the money blocked, sell names the shares held aside and what the sale books.

Eight frames from the three-competitor refs, in flow order: buy pad → conditions and charges → depth → placed → the order list → partly filled, filled and rejected. The sell pad and the CDSL authorisation live in 5b, not here. Holdings and the owned-stock screen are out; the pad is entered from 4a. The pad is full screen with the keypad docked, because quantity and price are both typed. Three things the refs get wrong and this fixes: order value is a live line, not a chevron you have to open; the sell pad in 5b states what you would book at this price against your average cost; and authorisation is asked once, up front, rather than at the last tap.
