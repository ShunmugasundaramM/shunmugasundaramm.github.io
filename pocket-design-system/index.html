01 · Overview

What mobile and desktop need before hi-fi

Pocket is a dark-first trading app with one accent colour. Before any hi-fi screen was drawn, every component the wireframes called for had to exist, work, and follow the same rules on a phone and in a browser.

The library is grouped the way Material 3 groups its own: action, containment, navigation, selection and text input. Same component, different density per platform. Each one links back to the wireframe round that first needed it.

06 · Accessibility

Rules that changed what got built.

SwipeToConfirm needs a tap option

WCAG 2.2 requires anything done by dragging to also work with a single pointer. Added a press-and-hold or a “Place order” button fallback.

Hit areas

WCAG 2.2 AA sets 24×24px as the minimum. Pocket keeps its stricter 44px on mobile; desktop table controls can go to 32px.

Focus never hidden

A focused control must not be fully covered by sticky content. Checked the TabBar, sticky order buttons and the desktop OrderWindow.

SEBI's July 2025 circular names WCAG 2.1. The WCAG 2.2 points above are a stricter target, not the stated legal minimum.
